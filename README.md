# トレーディングカード相場・仕入判断

GitHub Pagesで配信する静的サイトです。ポケモン・ワンピースのPSA10と、BOX・パックの成約履歴を閲覧できます。

## ローカル確認

リポジトリで `python3 -m http.server 8765 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8765/` を開きます。Chart.jsとsql.jsはCDNから読み込みます。データベースと画像マップは同じ公開先の `data/` を参照します。

計算・判定のテスト：`node --test tests/purchase.test.cjs`（追加パッケージ不要）。

## 仕入判断

- 実際の仕入価格を入力した場合と、過去7日安値を使った参考試算を区別します。過去安値は現在の出品価格ではありません。
- 売却手取 = 販売価格 × (1 − 販売手数料率) − 販売送料 − その他販売費。
- 利益 = 売却手取 − 商品代金 − 仕入時費用。利益率は商品代金と仕入時費用の合計に対する割合です。
- 仕入上限は最低利益額と最低利益率を両方満たす商品代金を円単位で切り捨てます。販売価格が5％・10％下がる場合も確認できます。
- 手数料・送料は変更可能な試算用の初期値です。契約や販売方法に適用される最新費用を取得する機能はありません。税金は計算に含みません。
- PSA10の参考候補は、利益・取得件数・最終取引の鮮度・予算・中立以上の相場トレンドを満たす商品です。同名・同型番で異なる商品ページがある場合は仕様確認を優先し、候補から除きます。
- 件数は取得できた成約のみです。市場全体の取引量、成約確率、売却所要日数を示しません。信頼度は取得件数と鮮度による目安です。
- 7日・14日集計とPSA10チャートの期間は閲覧時点の日本時間を基準にします。PSA10の当日／前日比は両日に成約がある場合のみ計算します。移動平均は観測がある取引日の点数を使います。
- BOX・パックの利益計算は閲覧時点の7日成約中央値を使います。既存の日次一覧は明示したデータ収集基準日を使います。パックの出品最安値は数量の比較条件が不明なため非表示です。

PSA10の仕入条件はブラウザのlocalStorageに保存します。入力した商品代金はページ内メモリのみで、再読み込み時に消えます。サーバーへの入力送信はありません。

## 公開

既存のGitHub Pages設定は `main` ブランチのルートです。HTML・`assets/` の変更を反映するとPagesが再構築します。データ収集処理自体はこの改修の対象外です。
